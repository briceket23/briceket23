## Selected research directions

### Self-supervised learning for malaria microscopy

Research on contrastive visual representations for malaria-infected cell classification, including label-fraction experiments, ResNet-based image encoders, and evaluation across microscopy datasets. The aim is to understand when pretraining helps under limited labels and how performance changes when a model is evaluated outside its source dataset.

### Cross-dataset transfer under limited labels

Experiments examine how source-label budget, fine-tuning strategy, and evaluation setting affect the transfer of pretrained vision encoders. The focus is on separating within-dataset performance from external-dataset generalization and documenting the conditions under which results hold.

### HLG-Net: multi-task parasite-stage classification

Research into hierarchical logic gating for parasite-stage classification using a shared-backbone, multi-head learning design, with attention to severe class imbalance. Manuscript and implementation status should be checked before citing this work as published or linking a code release.
